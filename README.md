# CD Valet

CD Valet is a sister app to DVD Valet in the Valet Ballet Series. It helps music collectors scan or manually enter CDs, then keep album, artist, format, notes, and local profile data on device.

## MVP Scope
- Scan UPC barcodes into a local CD library
- Add CDs manually when a barcode is unavailable
- Edit album title, artist, format, and notes
- Keep library data local-first with an optional local profile
- Maintain CD-specific privacy, support, and store metadata
