Account & Data Deletion Requests

  • CD Valet stores library data and any optional saved profile on your device.
  • To remove local data, you can clear the saved profile inside the app or delete the app from your device.
  • If you need help identifying what to remove, email TixPy@pinataro.com with subject CD Valet Data Deletion Help.

Quick Checks

  • App Version: confirm you are on the latest build.
  • Camera Access: if scanning is not working, make sure camera permission is enabled for CD Valet in iPhone Settings.
  • Library Refresh: if a scan does not appear right away, open the Library tab and tap Refresh.

Common Topics

  • Profiles: Saving a local profile is optional. Any user can open the app, scan CDs, and build a personal library immediately.
  • Scanning UPCs: Use the Scan tab to capture CD UPCs in batches. If the camera view is open but codes do not save, try tapping Reset and scanning again.
  • Library Queue: The Library tab shows queued UPCs saved on the device. If the list looks stale, tap Refresh to reload it.
  • Camera Permission: The app requests camera access only when you choose to scan. You can re-enable it later in device settings if you denied it the first time.
